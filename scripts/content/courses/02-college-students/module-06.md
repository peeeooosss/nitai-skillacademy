### Module 2 · The Three Modes of an AI Coding Assistant
Use the right mode for the task:

1. **Chat mode** (a browser chat): best for one-off scripts and learning — you ask, discuss, iterate.
2. **Inline editor** (VS Code + Copilot/Cursor): best when writing code yourself — AI autocompletes and assists as you type.
3. **Agent mode** (advanced assistants that edit files across a project): powerful for multi-file tasks — and best approached once you understand the basics.

Start in **chat mode** for this course. It's the fastest way to build intuition without fighting an editor.

### Module 4 · The Copy → Run → Understand Loop
Never paste code you don't understand into your brain's "done" pile. Use the loop:

1. **Copy** the AI's code for a small, specific task.
2. **Run** it — watch it fail or work.
3. **Understand** — paste the code back: *"Explain this line by line in simple words, and tell me what to tweak for {change}."* Then actually tweak it.

The loop's power: you build genuine coding intuition while AI handles the syntax. After 10 loops you'll read code you were terrified of a month ago.

### Module 6 · Best Practices (Low Cost, High Value)
A few habits make AI-assisted coding safe and scalable:

- **Never run code that asks for your passwords or deletes data without reading it.**
- Keep scripts in a folder per project with a one-line comment above each.
- Prefer **standard libraries** and small scripts for student tasks — less to break, easier to debug.
- When stuck, give the AI the **full error message**, not "it doesn't work".
- Ask AI to **add comments** — they teach you and future-you.

Code you own is code you can trust. The script that copies files wrong once teaches you more than one that works perfectly and tells you nothing.

- Automate real tasks in your life — small wins compound.
- Protect secrets, test on copies, and use version control.
