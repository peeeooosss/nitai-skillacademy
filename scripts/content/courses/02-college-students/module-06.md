### Module 2 · The Three Modes of an AI Coding Assistant

AI coding assistants come in three modes, and each fits a different task. Chat mode is best for one-off scripts and learning. Inline editor mode assists while you type your own code. Agent mode edits files across a whole project - powerful once you understand the basics.

Start in **chat mode** for this course. It is the fastest way to build intuition without fighting an editor, and it is the mode this mission's exercises assume.

## Learning Objectives

- Distinguish chat, inline editor, and agent modes
- Match each mode to its best task
- Explain why chat mode is the learning path
- Choose the right mode for your current task

## The Three Modes

1. **Chat mode** (browser chat): best for one-off scripts and learning - ask, discuss, iterate
2. **Inline editor** (VS Code with Copilot or Cursor): best when writing code yourself - autocomplete as you type
3. **Agent mode** (assistants that edit files across a project): powerful for multi-file tasks
### The mode map
- Learning and one-offs: chat
- Writing your own code: inline
- Multi-file refactors: agent

## Why Chat Mode First

```text
Chat mode advantages:
1. Lowest friction - no editor setup
2. Fast iteration on small scripts
3. Natural for asking 'why' and 'what if'
4. Builds intuition without fighting an IDE
```
- The browser is enough for this mission's scripts
- Fundamentals stay fresh while friction stays low
- Save editor and agent modes until chat is comfortable

## Inline and Agent Later

### Inline editor mode
- Assists as you type code yourself - good once you write regularly
### Agent mode
- Edits files across a project - approach it after the basics
- Powerful for multi-file tasks, risky before you understand them
- The ordering is deliberate: chat, inline, then agent

## Key Takeaways

- Three modes: chat, inline editor, and agent
- Chat is best for learning and one-off scripts
- Inline assists while you write your own code
- Agent mode is powerful but comes after the basics
- Start in chat mode to build intuition with low friction

### Module 4 · The Copy-Run-Understand Loop

Never paste code you do not understand into your brain's 'done' pile. The Copy-Run-Understand loop keeps every AI-written line grounded in your own understanding: copy the code for a specific task, run it, then understand it by having the AI explain it line by line and tweaking it yourself.

The loop's power is that you build genuine coding intuition while AI handles the syntax. After ten loops, you will read code you were terrified of a month ago.

## Learning Objectives

- Run the three-step Copy-Run-Understand loop
- Ask AI for a line-by-line explanation of code
- Tweak code after understanding it
- Explain why the loop builds genuine intuition

## The Three Steps

1. **Copy** the AI's code for a small, specific task
2. **Run** it - watch it fail or work
3. **Understand** - paste it back: 'Explain this line by line in simple words, and tell me what to tweak for {change}'
### Why the third step is the whole point
- Understanding converts copying into learning
- Tweaking makes the understanding stick

## Explain Then Tweak

```text
The understand step:
Prompt: 'Explain this code line by line in
simple words, then show me what to change
to make it {goal}.'
1. Read the explanation
2. Make one change yourself
3. Rerun and see the effect
```
- Explain-then-tweak converts copying into understanding
- Each pass pairs reading with hands-on changes

## What Ten Loops Build

### The compounding effect
- Understanding plus editing beats passive copying
- After ten loops you read code you feared a month ago
### The rule that anchors it
- Never file code as done before you can explain it
- If a script must be smart, understanding it is non-negotiable
- The loop is fast enough to run on everything you paste

## Key Takeaways

- The loop is Copy, Run, then Understand
- Understanding means line-by-line explanation plus your own tweak
- Never file code as done before you can explain it
- Explain-then-tweak converts copying into learning
- Ten loops will make code you feared readable to you

### Module 6 · Best Practices: Low Cost, High Value

A few habits make AI-assisted coding safe and scalable. Never run code that asks for passwords or deletes data without reading it. Keep scripts organised in folders with a one-line comment above each. Prefer standard libraries and small scripts for student tasks.

When stuck, give the AI the full error message - not 'it does not work'. Ask AI to add comments that teach you and future-you. Code you own is code you can trust.

## Learning Objectives

- Apply the safety rules for running AI code
- Organise scripts with comments and folders
- Prefer standard libraries for student tasks
- Provide full error messages when stuck

## The Safety Rules

- **Never run code that asks for your passwords or deletes data without reading it**
- High-impact actions require reading and understanding first
- When in doubt, run on a copy in an isolated folder
### The trust test
- Would you show this script to a sysadmin?
- If not, understand it before you run it

## Organise Like a Pro

```text
The organisation habit:
1. One folder per project
2. One-line comment at the top of every script
3. Standard libraries for student tasks
4. Small scripts that do one thing well
```
- Comments document intent for you and future-you
- Small focused scripts are easier to debug
- Less to break is the best default

## Getting Unstruck Faster

### The full-error rule
- Give the AI the full error message, not 'it does not work'
- The error text carries the information needed to fix it
### The comment habit
- Ask AI to add comments - they teach you and future-you
- Code you own is code you can trust
- A script that fails while teaching you beats one that hides everything

## Key Takeaways

- Never run code that touches passwords or deletes data unread
- One folder per project, one comment line per script
- Standard libraries and small scripts are the student default
- Paste the full error message when stuck
- Code you understand is code you can trust
