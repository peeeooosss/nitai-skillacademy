# Course Outline — AI for College Students (UG & PG)

## Course Meta
- **Folder:** `02-college-students` (content dir: `scripts/content/courses/02-college-students/`)
- **Tier:** ₹2,000
- **Duration:** ~45 hours · 24 missions
- **Earning Math:** ₹5,000–₹15,000/month via freelance data entry automation, resume writing, no-code dev
- **Top 5 Unique Assets:**
  - ATS Resume Scanner with line-by-line rewrites
  - Placement Season countdown prompt packs
  - Voice mock interview grader (Hinglish)
  - Final-year project report templates
  - Entry-level AI gig board links
- **India Context Hooks:**
  - Campus placement season
  - Final-year project (FYP) stress
  - Tier-2/3 resource gaps

## Notes for Content Generation
- Each mission file = `module-NN.md` (NN = mission number, zero-padded).
- Each mission expands every sub-module in its outline (typically 5) using `### Sub-module K · Title`.
- Every submodule ends with a `**Example Quiz**` block (6 questions).
- Tone: simple English, Indian examples, warm Hinglish, ₹ earning angle.
- See `scripts/content/prompts/{slug}-prompt.md` for the full generation prompt.
