# Course Outline — AI for Working Professionals

## Course Meta
- **Folder:** `05-professionals` (content dir: `scripts/content/courses/05-professionals/`)
- **Tier:** ₹2,500
- **Duration:** ~45 hours · 24 missions
- **Earning Math:** Save 5-10 hours/week (₹5,000–₹10,000/month value); accelerate promotion by 6-12 months
- **Top 5 Unique Assets:**
  - Email Tone Converter (polite but firm)
  - Corporate prompt templates (Indian context)
  - Excel/Sheets formula generator
  - Promotion Pitch template
  - Departmental workflow mapping canvas
- **India Context Hooks:**
  - Urgent WhatsApp from bosses
  - Festival/holiday communications
  - Hierarchical corporate culture

## Notes for Content Generation
- Each mission file = `module-NN.md` (NN = mission number, zero-padded).
- Each mission expands every sub-module in its outline (typically 5) using `### Sub-module K · Title`.
- Every submodule ends with a `**Example Quiz**` block (6 questions).
- Tone: simple English, Indian examples, warm Hinglish, ₹ earning angle.
- See `scripts/content/prompts/{slug}-prompt.md` for the full generation prompt.
