# Course Outline — AI for Women & Homemakers (AI Didi)

## Course Meta
- **Folder:** `11-homemakers` (content dir: `scripts/content/courses/11-homemakers/`)
- **Tier:** ₹1,500
- **Duration:** ~35 hours · 24 missions
- **Earning Math:** ₹3,000–₹10,000/month via micro-freelancing or home micro-business
- **Top 5 Unique Assets:**
  - Voice-first regional language prompt tutorials
  - Online scam red flags safety module
  - Fridge leftovers to meal plan prompt
  - WhatsApp business message templates
  - Confidence-building small wins tracker
- **India Context Hooks:**
  - Household budgets with inflation
  - Helping kids with English-medium homework
  - Local WhatsApp community groups

## Notes for Content Generation
- Each mission file = `module-NN.md` (NN = mission number, zero-padded).
- Each mission expands every sub-module in its outline (typically 5) using `### Sub-module K · Title`.
- Every submodule ends with a `**Example Quiz**` block (6 questions).
- Tone: simple English, Indian examples, warm Hinglish, ₹ earning angle.
- See `scripts/content/prompts/{slug}-prompt.md` for the full generation prompt.
